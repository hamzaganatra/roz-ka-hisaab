ROZ KA HISAAB - APK BANANE KE STEPS (free, GitHub se)

1. github.com pe free account banao (ya login karo) aur ek naya repository banao, jaise "roz-ka-hisaab". Private rakh sakte ho.
2. Is zip ke andar ki saari files aur folders (www, .github, package.json, capacitor.config.json) us repository mein upload kar do.
   Dhyan do: ".github" folder bhi upload hona chahiye, warna build nahi chalega.
3. Repository mein "Actions" tab kholo. "Build APK" workflow chalega (ya "Run workflow" dabao).
4. 5 se 10 minute baad workflow ke andar "Artifacts" mein "roz-ka-hisaab-apk" aayega. Download karo, zip kholo, andar app-debug.apk hai.
5. Phone mein app-debug.apk kholo. "Is source se install ki ijazat do" poochhe to allow kar do. Install ho jayegi.

Data phone ke andar app ke storage mein rehta hai. App uninstall karne se data chala jata hai, is liye Accounts tab se Backup bhejte raho.
Is APK ke andar koi internet permission ya server nahi hai.
